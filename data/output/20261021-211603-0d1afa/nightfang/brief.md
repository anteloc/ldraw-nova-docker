# "Nightfang" – Le Mans-style hypercar (yellow / black)

User request: "an awesome SNOT car", then "most spectacular style, yellow and black".
Chosen concept: endurance-racing hypercar (Le Mans prototype). Low wedge nose, long
rear deck, cockpit canopy, tall shark-fin and big rear wing, wide flanks, exposed wheels.

## Scale / layout (X across, -Z forward, +up = -Y, ground Y=0)
- 6 studs wide on the touring wheel package (6157 holder, 6014b rim, 6015 tyre, track 92).
- 24 studs long, axles at z=-7 and z=+6 studs; tyre envelope diameter 50 / width 28.
- Chassis + fenders copy the proven road-vehicle pattern (spine plates, 98282 mudguards), re-laid out
  for length 24; the bodywork, cabin, fascias, SNOT skins and wing are new.

## Palette
Yellow (14) body, black (0) trim / intakes / wing / tyres, trans-black (40) canopy,
trans-orange / trans-red lamps, a few light-grey accents only on rims/exhausts. Yellow rims.

## SNOT features (each uses an inspected side-stud interface)
1. Nose fascia and tail fascia: 4070 headlight bricks with forward/rearward studs, round trans lamps (6141) on them.
2. Flank skins between axles: 87087 side-stud bricks / 4070 on outer lanes with tiles mounted directly on
   outward studs -> smooth studless doors with black intake slots.
3. Rear wing: plates/tiles on side-stud mounts, endplates standing sideways.
4. Hood centre line: curved slopes + tiles for a studless bonnet.

## Build order
chassis+wheels -> body deck + fenders -> nose/tail fascias -> flank skins -> cabin -> tail/wing -> review.
